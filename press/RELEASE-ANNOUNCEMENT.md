# ScreenBox 0.10.0 (12) — 首个公开预览版

**ScreenBox 发布首个公开版本。**

手机里的截图越积越多，想找一张却要翻很久——这是 ScreenBox 要解决的问题。它在设备上扫描截图、本地识别文字、按内容归类，并帮你安全清理不再需要的图。

**这个版本能做什么**

- 按截图里的文字搜索（日期、金额、订单号、一句话）
- 自动归类：聊天 / 订单 / 二维码 / 游戏 / 社交，不确定就留空
- 按分类、来源、时间、大小筛选，条件可保存
- 清理工作台：重复、可能过期、近乎空白、验证码、旧通知、旧游戏截图，每条带理由
- 收藏 / 保护 / 系统授权删除，删除前三次核对

**隐私**

不申请网络权限，OCR 模型随包打包，全程本机处理。无需 Root，无需账号。

**兼容性（如实说明）**

Android 15 真机完整验证；Android 10–14 尚未真机验证（权限分支有单元测试，但不等于真机通过）。最低 Android 10。

**为什么是 Preview 不是 Stable**

核心流程可用、115 项单元测试全绿，但还有两个硬缺口：Android 10–14 未真机验证、删除的实际执行（会真删用户图片，本轮不做破坏性验证）。所以首个版本标记为 Preview，不冒充稳定版。
